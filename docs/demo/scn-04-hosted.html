3. The verifier catch

deterministic, and run again offline when the results are graded

A citation can point at something real and still not establish what it is cited for. An order for a drug is not a record that the drug was taken; a withdrawn result is not a result. The check below re-reads every citation against the patient record and the trial text, and rejects the ones that cannot carry the claim.

These faults are injected deliberately, so that the catch is reproducible rather than dependent on a model happening to make the mistake. Organic catches from this run, if any, follow.

Injected fault F6 — An osimertinib order cited as treatment exposure. The resource exists, the path resolves, the drug is right and the date is real — every other check passes, and the relation is the one the state needs. Order intent is not exposure, so the assessment rests on nothing. This is the fault the section 3 demonstration turns on.

Cited: MedicationRequest/medreq-osi

Rejected: citation_cannot_establish_state

MedicationRequest/medreq-osi is outside the evidence-bearing boundary (order_intent_is_not_exposure), so not_met rests on nothing

Injected fault F9 — The only ECOG score in the record was written two weeks after the Assessment Time. At screening it did not exist.

Cited: Observation/obs-ecog-late

Rejected: evidence_after_assessment_time

Observation/obs-ecog-late did not exist at the Assessment Time
