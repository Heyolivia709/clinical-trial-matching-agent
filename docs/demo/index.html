Clinical Trial Matching Agent — Trace Reports

One page per screening run. Generated from frozen artifacts; each opens offline with no network fetch.

Each report works one eligibility criterion through in full, shows the deterministic verifier rejecting a citation that cannot carry the claim, and puts the agent beside a one-shot baseline that was handed the whole patient record.

  • SCN-01 — the resolvable patient: every oncology fact is final, dated to the day, and says what it appears to say.
  • SCN-02 — a retracted PD-L1 result, and two ECOG scores from the same day that disagree.
  • SCN-03 — a preliminary performance status, and a drug administration dated only to the year.
  • SCN-04 — an order that was never administered, a result recorded after screening, and a protein stain standing in for a different test.
  • SCN-04, failing run — the agent cites a fact no tool returned, is rejected, corrects itself, and is rejected again. The criterion ends as unknown with verification_failed.

The written results — every count the measurement plan asks for, with its denominator — are in development-results.md, and what the five-minute check did and did not verify is in five-minute-check.md.

These are one recorded claude-sonnet-5 run, replayed from committed transcripts. Decoding is unpinned — the model rejects a temperature parameter — so the transcript is the reproducibility, and no count here is an expected value across runs. The agent's first citation was rejected five times out of six; what the reports show is what the verifier did about it.
