§ 7

Evidence verifier and correction

deterministic · one correction maximum

One verifier implementation serves two separated roles. It grades the final outputs of every variant offline, and it feeds back into the agent loop for the full system only. Verification failure triggers exactly one targeted correction; a second failure yields unknown with reason verification_failed.

Two roles, one implementation
Grading — every variant, including the baselines and ablations. Results never flow back into the system under test.
Feedback — the full agent only. Its verdict triggers the single correction inside the loop.
Because the full system's outputs have passed through one correction, citation validity is reported at three points: the expression-aware control, the full system before correction, and the full system after correction. This asymmetry is the measured architectural difference and is stated wherever the comparison appears.
failure separation · infrastructure failures — unavailable model endpoint, malformed snapshot, tool exception — are recorded as failures and are never scored as correct uncertainty.
