Clinical Trial Matching Agent

An agent that screens a patient record against trial eligibility criteria, one criterion at a time, and shows its work.

Every assessment cites the patient fact it rests on and the exact trial sentence it answers. A deterministic verifier checks each citation before it reaches the output, and anything it cannot verify is reported as unknown with the reason it could not be resolved — never as a guess.

The reports

One self-contained page per screening run. They open offline and fetch nothing.

  • SCN-01 — the resolvable patient
  • SCN-02 — a retracted result, and two performance scores from the same day that disagree
  • SCN-03 — a preliminary status, and a drug dated only to the year
  • SCN-04 — an order never administered, a result recorded after screening, and a stain standing in for a different test
  • SCN-04, a run that fails — the agent cites a fact no tool returned, is rejected, corrects itself, and is rejected again

The write-ups

  • Development results — every count the measurement plan asks for, with its denominator
  • The five-minute check — what was verified about the report, and what was not
  • Specification · Decision records · Source

Read these two things before the numbers

The runs replay authored transcripts, not a recorded model run. A scripted answerer reads the packets the loop builds and replies by rule. The counts therefore measure the harness rather than a model, and the agent's agreement with the expected labels is consistent by construction. A result about model behaviour has to be re-recorded through a real adapter, and every run records which one produced it.

Screening workflow labels only. This project does not diagnose, determine clinical eligibility, recommend treatment, or enrol patients. The patients are synthetic. Recruiting status, site availability, and actual eligibility must be verified through ClinicalTrials.gov and the study team.
