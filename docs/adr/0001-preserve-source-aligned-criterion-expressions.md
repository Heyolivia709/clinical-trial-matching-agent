# Preserve source-aligned criteria and derive expression trees

ClinicalTrials.gov eligibility bullets often contain conjunctions, disjunctions, and conditional clauses. Phase 1 preserves each source criterion and its provenance as authoritative while deriving a versioned expression tree over atomic propositions; flattening into unrelated checklist items was rejected because it loses trial semantics, and replacing source text with model paraphrases was rejected because it breaks evidence grounding.
